How to use on the drawing
  1. Pick two points (for example pole 82W and 81E).
  2. Count blue grid squares across (ΔX) and up (ΔY). Part squares are allowed, e.g. 7.5.
  3. Tap + / − or type the two numbers.
  4. Set the real length of one square. Default 10 m matches a 10 mm grid at 1:1000.
  5. The red line is the slope distance. The answer stays pinned at the top.

Decode an existing ID

Loads tag number, curve ID, distance, speed and mark from a programmed tag.

ID HEX map (RFID ID definiation.xlsx)
  1. 19 04 — fixed Tramways RFID header
  2. C — C-curve 彎位
  3. 0 — reserved
  4. 01–04 — Tag 1 / 2 / 3 / 4 (for curve)
  5. Curve ID — decimal 1–255 stored as hex 01–FF
  6. Distance — decimal metres stored as hex. Definition examples: Tag1 = 14 (20 m), Tag2 = 0A (10 m), Tag3 = 0A (zone end), Tag4 = 00
  7. 0 — reserved
  8. Speed — 0 none, 1 = 8 km/h … E = 45 km/h
  9. Mark — tag mark number on surface, not converted
Built from RFID ID definiation.xlsx sheet “ID definiation”, row C-curve 彎位. Curve ID and distance convert decimal → hex. Surface mark is copied as written.
